# Studio-Led Film Techniques, Tech-Client Work 2025-2026

Status: partial. About 20 tool calls, past the 15-call guide, to reach the minimum of seven studios. Only four studios yielded client work. Several entries rest on search-result summaries, not fetched pages. Source access was limited: LBBOnline returned HTTP 403, and BUCK, Ordinary Folk, basement.studio, Koto, Instrument and Gunner returned no relevant film work.

## Key Question 1: How do these studios turn an abstract software idea into a visual concept?

### Takeaway
The few studio-owned descriptions found frame software as a character or a world rather than a feature list. Giant Ant makes the buyer a cast member; ManvsMachine treats the software as a punk underdog against legacy tools; Tendril describes glass and subsurface material for UI. Only a small number of quotes were retrievable.

### Cited Findings
- Optimizely briefed Giant Ant with "Optimizely invited us into the world of Mark Eting, the planet's best marketer" (concept, in the studio's words); the series is four mini-brand films for an "AI digital experience platform" — [Stash Media, Giant Ant / Optimizely](https://www.stashmedia.tv/giant-ant-tells-the-tales-of-mark-eting-for-optimizely/) (dated 2026-06-23 in the fetched page).
- ManvsMachine's Canva Affinity film aimed to "resonate with existing Affinity users while exciting creatives who had never encountered the software before," with a "punk attitude" that "challenges legacy software" — [Red Dot interview](https://www.red-dot.org/magazine/interview-with-manvsmachine). Publication date not shown (page carries "Copyright Red Dot 2026"). Search summary also cites a Stash write-up describing "motion, typography, and product demo all rolled into one" — [Stash Media search result](https://www.stashmedia.tv/?p=54596) (not fetched; unverified).
- Tendril's IBM Think 2026 films for three new software launches, built from a design sprint, "explored the element of glass and subsurface materials, reinterpreting UI elements with tactility and clarity"; director credited as Rafael Eifler — [Shots.net, IBM launches new campaign from Tendril](https://shots.net/news/view/ibm-launches-new-campaign-from-tendril) (search-result summary; article not fetched; unverified in full text).

### Inferences
- Giant Ant and ManvsMachine both cast the software through a personality (a marketer, a rebel tool). This is the most reusable abstraction move in the findings.
- Tendril's UI treatment (material, not screen capture) is a different route: product UI becomes a surface, not a recording.

### Gaps
- BUCK, Ordinary Folk, basement.studio, Oddfellows (motion studio), Koto, Instrument, Gunner: no studio-authored description of abstraction found.
- Note: a search for "Oddfellows" returned a Vancouver feature film studio (Backrooms co-producer; [Daily Hive, 2026-07-14](https://dailyhive.com/vancouver/vancouver-film-studio-oddfellows-backrooms-warner-bros)). It is not the motion studio. Excluded.

### Takeaway

### Inferences
