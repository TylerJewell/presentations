Install Akka

Your harness reads instructions from akka.ai and installs the Akka plugin. If your harness does not support plugins, it installs the Akka MCP server via the CLI instead. Each step is documented and requires your consent. Tested with Aider, Antigravity, Claude Code, Claude Tag, Claude.ai, Codex CLI, Cody, Cursor, Devin, Factory, Gemini CLI, GitHub Copilot coding agent, GitHub Copilot in Visual Studio, GitHub Copilot in VS Code, Jules, Junie, Roo Code, Trae, Warp, and Zed.
