Create agentic systems from composable parts.

Component client

The component client is how one component calls another.

Agents

An agent interacts with an AI model to perform a specific task.

Autonomous agents

Agent and task state persist as it goes, so work survives crashes and restarts.

Workflows

A business transaction lives in one place, and the workflow either keeps it moving or rolls it back when a step fails.

Event sourced entities

State is rebuilt by replaying those events, and gives you a complete history of how the state came to be.

Key value entities

Akka guarantees exactly one instance of each entity across the whole cluster, so commands are handled one at a time.

Views

Views let you read across many entities, or find an entity by something other than its id.

HTTP endpoints

HTTP endpoints accept and return JSON by default.

gRPC endpoints

Protobuf’s forward and backward compatibility make service-to-service calls safe to evolve without breaking existing clients.

MCP endpoints

What you expose becomes tools the model can call on its own behalf.

Timed actions

Timers run at least once: if the call fails, the timer reschedules itself until it succeeds.

Consumers

Consumers read a stream of events, from an entity’s journal, from key value state changes, or from a message broker topic.
