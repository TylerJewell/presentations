Principle 07

Controls can execute in pre-production or production.

The same controls execute in documents, pre-production, and production.

Documents
Checks whether a required attestation is on file and still fresh — not runtime behavior.
Pre-production
Execute tests, evaluations, model analysis, and red teaming requirements prior to a model change.
Full retestModel swap, architecture change, new data source, new jurisdiction
TargetedPrompt or parameter change, retrain, vendor model drift
Records onlyBug fix, ownership transfer, attestation lapse
Production
Akka enforces guardrails, HITL, sanitizers, and evals against running systems.
